# MCI Eyelashes — company website

Real business site (B2B wholesale eyelash **supplier**, not a salon). MCI is one person, established 2019, with no factory or office of its own: the lashes are made by partner workshops in Purbalingga that MCI manages. The site once claimed "direct factory, own production floor, not a trading company"; that was false and was removed in November 2026. Never write it again. React 19 + Vite SPA, repo `mcieyelashes-boop/mci-eyelashes`. Hosted free on Cloudflare since 20 November 2026: the Worker `mci-eyelashes` (static assets from `dist/`, settings in `wrangler.jsonc`) builds and deploys every push to `master`, and serves `www.mci-eyelashes.com`; `worker/index.js` only redirects the bare domain to www. DNS for the domain is in the owner's Cloudflare account. Vercel paused the owner's account (402) and is no longer used; `vercel.json` stays because the build turns its redirects and headers into `dist/_redirects` and `dist/_headers`.

Rules learned the hard way here:

1. **All business claims come from the owner.** MOQ, prices, client counts, certifications, testimonials — never invent or "improve" them. The site once shipped with fabricated offer numbers that had to be stripped (commit `f379b33`). Unknown value → visible placeholder + ask.
2. **Brand assets**: the navbar/favicon logo is the gold MCI monogram (`public/logo-mci.png`) with NO wordmark text next to it. Don't regenerate logos; use the owner's file exactly. The site loads `public/logo-mci-192.webp`: that file scaled down with its baked-in grey checkerboard background removed (the PNG has no real transparency). The owner approved this correction; do not point the site back at the raw PNG.
3. **Changed static assets need a new filename** — the CDN can serve old bytes for a re-used name (that's why it's `logo-mci.png`, not `logo.png`).
4. **A fix isn't done until the change is visible on `www.mci-eyelashes.com`** in a fresh load — pushing to GitHub is not proof; check the production deployment actually promoted.
5. Design direction the owner approved: dark luxury, gold + teal/navy accents, minimal — and the splash/hero (robot image, full-bleed, head never cropped) stays unless the owner asks.
